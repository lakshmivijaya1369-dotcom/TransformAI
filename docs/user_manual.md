# User Manual

## Start the application
Follow the installation and startup steps in the root README.

## Use the application
1. Open `http://127.0.0.1:8000`.
2. Upload a PDF/TXT file or paste source content into the text area.
3. Select Summary, Quiz, Report, or Study Q&A.
4. Select a detail level.
5. Click **Generate with AI**.
6. Wait for the generated content to appear.
7. Click **Download .txt** to save the result.

## Tips
- Use a text-based PDF for best extraction results.
- Keep source material relevant to the selected task.
- AI output should be checked for accuracy.
- Do not upload confidential personal or institutional data.
